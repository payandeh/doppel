Doppel

A body double for your API responses. Override the JSON body and/or status code of REST calls (fetch and XHR). Reload the page you're testing after turning on new overrides if requests already ran.

Your overrides are only stored in this browser. If you remove the extension, they are lost.

Overrides are saved to doppel.json in the folder you pick, and every change is saved automatically. After reinstalling the extension (or on another computer), choose the same folder and your overrides load again. You can also keep the folder in Git to share mocks with your team.

How to override a request

  1. Open DevTools → Network tab.
  2. Right-click a request → Open using Doppel.
  3. Edit the body and/or status (leave empty to keep the real one) → Save.
